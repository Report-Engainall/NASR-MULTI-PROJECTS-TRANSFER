# Extracted Projects

This directory contains the contents of every ZIP archive found in the root of NASR-MULTI-PROJECTS-TRANSFER.

Each archive is extracted into its own subfolder to preserve its original files and prevent same-name files from overwriting each other. The source ZIP archives remain untouched in the repository root.

## Structure

`EXTRACTED_PROJECTS/<archive-name-without-.zip>/`

See `_EXTRACTION_REPORT.md` for archive hashes, file counts, duplicate detection, and extraction status.
