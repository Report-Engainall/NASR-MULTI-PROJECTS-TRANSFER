# دليل الأدوات والمكتبات المجانية ومفتوحة المصدر المقترحة لمتجر الأغبري

**القاعدة:** مجانيّة المكتبة لا تعني أن كل خدمة مستضافة تستخدمها مجانية، ولا أن النموذج نفسه يسمح تجاريًا دون قيد. افحص LICENSE ونسخة الحزمة وشروط النموذج والمزود وقت التثبيت. لا تُدخل أي مفتاح API إلى المتصفح أو GitHub.

## 1. الموجود في Nasr1 ويجب إعادة استخدامه أولًا

بحسب package.json الذي تمت قراءته قبل إنشاء هذه الحزمة، يحتوي المشروع على:
- React وReact DOM — واجهات المستخدم.
- React Router — المسارات والتنقل.
- Zustand — الحالة المحلية الخفيفة.
- @supabase/supabase-js — واجهة قاعدة البيانات والمصادقة والخدمات الحالية.
- lucide-react — الأيقونات.
- Vite وTypeScript — البناء والتحقق.
- Vitest موجود في إعدادات المشروع.

قبل تثبيت أي مكتبة أدناه، افحص هل توجد أداة تؤدي الوظيفة أصلًا، وهل يوجد قفل إصدارات مناسب. لا تستبدل package manager أو lockfile بصورة جماعية.

## 3. مزودو الذكاء الاصطناعي: مجانيون بحدود وليسوا مجانيين بلا نهاية

- Gemini API: تتوفر فئة مجانية لبعض النماذج وبحدود معلنة. صفحة الأسعار الرسمية تقول إن بيانات الفئة المجانية قد تُستخدم لتحسين المنتجات؛ لذلك **لا تُرسل بيانات مالية أو شخصية خام إليها**. راجع https://ai.google.dev/gemini-api/docs/pricing.
- OpenRouter: تعرض صفحة الأسعار وقت إعداد هذه الوثيقة خطة مجانية فيها نماذج مجانية محددة وحد أقصى مذكور يبلغ 50 طلبًا يوميًا؛ القائمة والحصص قابلة للتغيير. راجع https://openrouter.ai/pricing.
- Hugging Face Inference Providers: تعرض الوثائق الرسمية رصيدًا شهريًا صغيرًا لحساب Free قدره 0.10 دولار في لقطة الأسعار التي تم الاطلاع عليها؛ لا تصفه بأنه استخدام غير محدود. راجع https://huggingface.co/docs/inference-providers/en/pricing.
- Ollama أو Transformers.js/ONNX: بدائل محلية، لكن ليست مجانية التكلفة التشغيلية؛ يلزم حساب الموارد، أحجام النماذج والتراخيص.

يجب أن يكون AI Gateway قابلاً لتعطيل أي مزود واستبداله، ويسجل provider/model/version/request ID والحصة والحالة. إذا نفدت الحصة أو تعطل المزود، انتقل إلى مزود احتياطي مهيأ أو تحليل حتمي rule-based مع رسالة صريحة؛ لا تدّع أن AI اشتغل إن لم يحدث اتصال حقيقي.

## 4. المعمارية التي تمنع التكاليف والازدواج

- الأرقام التجارية (الأسعار، الإجماليات، الأرباح، الضرائب، أرصدة الذمم، مخزون متاح) تحسب عبر SQL/Domain Engine حتمي، لا بواسطة LLM.
- النموذج اللغوي يفسّر metrics محسوبة ومقيدة بالمصدر والفترة والعينة والافتراضات؛ لا يخترع بيانات ولا ينفذ معاملة مالية مباشرة.
- كل خدمة خارجية يجب أن تكون خلف Adapter أو واجهة واحدة، مع timeout/retry/rate-limit/circuit-breaker وfallback.
- لا ترفع ملفات أو أسماء العملاء أو الأرقام الحساسة إلى مزود خارجي دون سياسة وموافقة صريحة وتنقية مناسبة.
- لا تثبّت أي حزمة قبل مراجعة الترخيص والإصدار والصيانة والحجم وثغرات الاعتماديات. احتفظ بـ lockfile وSBOM/قائمة تراخيص إذا توفرت أداة مجانية مناسبة في خط CI.

## 5. القرار الافتراضي

ابدأ بإعادة استخدام React/Router/Zustand/Supabase/Vite/TypeScript الموجودة. من الخيارات أعلاه، المرشحون العمليون غالبًا هم Zod للتحقق الموحد، Papa Parse/ExcelJS لمحرك الملفات، PDF.js لاستخراج PDF، وPlaywright لاختبار المسارات؛ لكن لا تثبّت شيئًا تلقائيًا قبل إثبات الحاجة في الكود الحالي. لا توجد مكتبة واحدة تجعل الحسابات والذكاء واستخراج كل الملفات آمنة ودقيقة دون ربط واختبارات.


## 6. تحقق محدث من خيارات AI المجانية — لقطة 16 أكتوبر 2026

هذه **خدمات اختيارية ذات حصص مجانية** وليست مكتبات مفتوحة المصدر ولا ضمانًا للاستمرار بلا تكلفة:

- **OpenRouter Free:** تعرض صفحة الأسعار الرسمية الآن 25+ نموذجًا مجانيًا، وأربعة مزودين مجانيين، وحدًا يصل إلى 50 طلبًا في اليوم؛ توضح صفحة الأسئلة أن النماذج المجانية محدودة عادةً بـ20 طلبًا في الدقيقة و50 في اليوم، وقد يرتفع الحد اليومي بعد شراء رصيد مدفوع. راجع [صفحة الأسعار](https://openrouter.ai/pricing/) قبل كل تفعيل. لا تعتمد على هذه الحصص كسعة إنتاج مضمونة.
- **Hugging Face Inference Providers:** صفحة الأسعار الرسمية تعرض 0.10 دولار شهريًا لحساب Free، مع التصريح بأن الرقم قابل للتغيير وأن الاستهلاك الإضافي مدفوع عند شراء رصيد. هذا رصيد تجريبي ضئيل وليس خدمة مجانية غير محدودة. راجع [التسعير الرسمي](https://huggingface.co/docs/inference-providers/en/pricing).
- **Gemini API:** الخطط المجانية تختلف حسب النموذج وطريقة التنفيذ؛ جدول الأسعار الرسمي يميز بين free-tier وpaid-tier، وبعض الاستخدامات في الفئة المجانية تشير إلى أن البيانات قد تُستخدم لتحسين منتجات Google. لذلك لا ترسل بيانات العملاء/المحاسبة/الأسرار الخام إلى free-tier؛ يلزم تنقية البيانات وسياسة موافقة صريحة. راجع [الأسعار والسياسات حسب النموذج](https://ai.google.dev/gemini-api/docs/pricing).
- **Ollama / النماذج المحلية:** قد يوفر تشغيل النموذج محليًا طلبات دون رسوم API لمزود سحابي، لكنه ليس صفر تكلفة تشغيلية: يحتاج CPU/GPU وذاكرة وتخزين/استضافة، ولكل نموذج ترخيصه الخاص. افحص ترخيص النموذج تحديدًا ولا تفترض أن كل أوزان النماذج لها نفس الحقوق.

**سياسة Bolt الملزمة:** لا تُشغّل أي endpoint مدفوع أو مسار يمكنه تجاوز الرصيد المجاني تلقائيًا. خزّن provider/key على الخادم، وضع سقف استخدام صريحًا، وافصل free/local/paid في Provider Registry. عند نفاد الحصة، استعمل مزودًا مجانيًا مهيأً أو محركًا حتميًا داخليًا؛ لا تحوّل الإخفاق إلى نجاح AI وهمي.
