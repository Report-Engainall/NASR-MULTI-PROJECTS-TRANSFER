# تشغيل جامع المصادر داخل بيئة Bolt

هذا السكربت أداة جمع، لا أداة دمج. شغّله من جذر نسخة Nasr1 التي تعمل عليها Bolt:

    node docs/bolt-source-reconciliation/tools/collect-source-inputs.mjs

النتيجة تُحفظ افتراضيًا في مجلد مؤقت خارج شجرة التطبيق، ويمكن تحديد مكان آخر عبر المتغير AGHBARI_SOURCE_WORKDIR. يجمع السكربت مرايا Git للمستودعات المرصودة، ويحاول جلب فروع main/tags ومراجع PR، وينشئ نسخة عمل من الفرع الافتراضي المتاح لكل مستودع. لا يمسح أو يغيّر مصادر GitHub الأصلية، ولا يدمج أي ملف في Nasr1، ولا يجري أي تعديل على قاعدة البيانات.

## ما الذي ينتجه؟

- مجلد mirrors يحتوي مراجع Git وتاريخ المستودعات التي أمكن الوصول إليها.
- مجلد working-trees به ملفات الفرع الافتراضي للمصادر التي أمكن تنزيلها؛ ارجع إلى Manifest لمعرفة SHA الدقيق.
- مجلد archives لنسخ أرشيفات متجر الأغبري التي عُثر عليها في الأشجار المنسوخة، مع الحجم وSHA-256 المحسوب من البايتات.
- COLLECTION_MANIFEST.json وCOLLECTION_REPORT.md مع حالة كل مصدر والأخطاء.

## الحدود

- المستودعات الخاصة قد تفشل إذا لم تكن جلسة Git في Bolt مصرحًا لها؛ لا تُضمّن أسرار المصادقة في السكربت.
- السكربت لا يستطيع اختلاق ZIP المفقود بحجم 95,377,100 بايت أو الأرشيف الإضافي متعدد المشاريع إذا لم يكونا موجودين في المصادر المعروفة.
- لا يستخرج RAR/ZIP تلقائيًا؛ اختبر سلامة الأرشيف أولًا، ثم استخرجه بأداة حديثة في مسار معزول، وتعامل مع كل فشل كحالة مسجلة.
- لا يعتبر جمع المصادر إثباتًا لصحة الميزات أو نجاح البناء.
- لا تجعل ملفات mirrors/snapshots المؤقتة جزءًا من حزمة الإنتاج أو deploy output، ولا ترفع محتوى .env أو المفاتيح أو البيانات الحساسة.

بعد تشغيله، اتبع BOLT_EXECUTION_MANDATE.md لمقارنة الميزات ونسخ الفروقات المفيدة فقط إلى Nasr1، مع سجل منشأ واختبارات.
